# 현장 사용 안내 (웹 POP)

생산실적관리 POP 는 이제 **브라우저로 접속**해서 씁니다. 현장 PC·태블릿에 설치할 것은 없습니다.

## 접속
- 주소: `https://(프로젝트).vercel.app` — 배포 후 담당자가 알려 줍니다(배포 방법은 [deploy-vercel.md](deploy-vercel.md)).
- 브라우저: 크롬 또는 엣지. 태블릿은 **가로로** 놓고 씁니다(화면은 PC 화면을 그대로 줄여서 보여 줍니다).
- 주소를 바탕화면·홈 화면에 바로가기로 만들어 두면 편합니다. "키오스크 모드" 바로가기는 쓰지 마세요(전체화면을 풀 수 없게 됩니다).

## 전체화면과 오른쪽 위 버튼
- **로그인 버튼을 누르면 전체화면**으로 바뀝니다.
- **_ 버튼**: 전체화면을 풉니다. PC 에서는 작업표시줄이 보여 다른 프로그램으로 넘어갈 수 있습니다. 다시 전체화면으로 하려면 키보드 F11 을 누르거나, 로그아웃 후 다시 로그인합니다.
- 아이패드처럼 전체화면을 지원하지 않는 기기에서는 _ 버튼이 보이지 않습니다.
- 로그인 화면의 X(프로그램 종료) 버튼은 없습니다. 브라우저 탭/창을 닫으면 됩니다.

## 화면 키보드 (터치 PC)
- 태블릿은 입력 칸을 누르면 기기 키보드가 자동으로 뜹니다.
- 터치 PC(Windows 11)는 다음 설정을 한 번 켜 주세요: **설정 > 시간 및 언어 > 입력 > 터치 키보드 > "키보드가 연결되지 않은 경우 터치 키보드 표시"**. 입력 칸을 손가락으로 누르면 키보드가 뜹니다.
- 예전 프로그램처럼 품목 검색·참고사항 두 칸에서만 뜨게 할 수는 없습니다.

## 기기에 기억되는 값
- 마지막에 고른 공정·작업장·설비·작업자, "아이디 저장"은 **그 기기의 브라우저 안**에 저장됩니다.
- 브라우저 방문 기록·쿠키를 지우면 함께 지워집니다. 다시 한 번 고르면 됩니다.
